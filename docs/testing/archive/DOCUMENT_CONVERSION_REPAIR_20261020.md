## 关键实际判据

1. 根目标、段落目标、同文档标题目标：预检 `writeAttempted=false`，原生转换调用增量为零；前后正文及原生文件相同。
2. 文档转标题的前插/后插：两次各一次原生调用，源 ID 成为目标文档里的标题；原目标正文、源标题/段落/列表/代码保留，位置正确。重放零额外转换，异参返回 `idempotency_conflict`。
3. 标题转文档：默认根目录、指定父文档、指定同级位置均成功；标题 ID 保留，中文、emoji、子标题和代码读回正确，源文档前后章节保留。
4. 预检后合法修改目标父文档：旧提交 `state_changed`，没有原生转换。
5. 原生文件必须来自 `/data/<notebook>/<ID path>.sy`，不能把 API 错误 JSON 当作有效文档。
