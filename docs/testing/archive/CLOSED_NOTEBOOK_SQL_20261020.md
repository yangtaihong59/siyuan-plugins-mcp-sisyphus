# 关闭笔记本后的 SQL 可检索性实测

SiYuanDev 3.8.7，2026-10-20；通过本轮临时笔记本进行了两次关闭/重开。写入全部走 dev MCP 预检与提交，查询走真实内核 /api/query/sql，避开插件权限拒绝以观察内核实际数据。未修改产品。

## 结论

关闭状态返回 true 后仍存在可检索窗口；随后 blocks 索引数据消失。第一轮关闭后约 1.27 秒仍有数据，约 4.30 秒采样已为零；第二轮约 0.26 秒仍有数据，约 1.27 秒采样已为零。采样时刻不是精确清理完成时间，更不能作为固定等待期限。重新打开后两轮均恢复相同记录。不能仅以 closed 标记作为即时 SQL 权限隔离依据。
