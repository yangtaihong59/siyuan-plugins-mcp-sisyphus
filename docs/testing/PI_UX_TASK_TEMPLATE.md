# 角色体验任务卡（每张卡启动全新 pi 会话）

由主代理填好后只把此卡与允许的工具交给体验代理。不要一并给完整计划、源码、答案和功能执行日志。

- runId / caseId：填写本轮编号。
- 角色：新手／日常整理／科研／数据库管理／迁移／学习／CLI／远程用户／管理员之一。
- 可访问的测试端点与范围：填写已核对的目标与夹具范围。
- 用户自然任务：例如“把这三段会议记录整理成一篇笔记，给两项待办加状态，之后找出尚未完成的任务”。写任务，不写要调用的 action。
- 已知背景：只给该角色合理知道的信息，例如笔记本名称、测试文档标题、任务截止日期。
- 时间/工具调用上限：由主代理填写。建议 quick 单任务 3 分钟/20 次；标准单任务 8 分钟/50 次，超过即记录未完成。
- 允许的实际修改：本轮明确登记的夹具；其他数据只读或不可访问。
- 禁止副作用：不修改权限、全局设置、已有数据，不同步/回滚/发反馈/购买。不能获得权限时如实停止。

你只能使用公开工具、工具 help/Resources（CLI 角色可用公开 CLI help）。不能读源码、测试脚本或答案，不能猜造 ID。先按自然任务尝试；卡住时记录位置和错误。一次公开 help 辅助恢复后仍不能完成就停止，不无限试错。

请输出：

1. 完成/部分完成/未完成，以及实际结果引用。
2. 按时间的工具轨迹和错误（由控制器保留原始响应；不得只给口述）。
3. 哪一步不容易发现/理解，缺少什么信息，是否需要人工介入。
4. 总调用、help、非法参数、重复读取与恢复次数；无可观测数据填 unknown。
5. 你认为的问题、证据与临时绕法。推测必须标 hypothesis，不能把权限正常拒绝认定为故障。

主代理在会话之外执行独立读回，检查真实任务是否完成；体验代理自称完成不能直接判 passed。
